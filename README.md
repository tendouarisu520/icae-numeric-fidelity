## Reproduce the results

Extract the entire ZIP into one directory. From that directory, run the following commands with Python 3.10 or newer. Both use the Python standard library. The first checks the file digests, counts the prediction and score records, reconstructs the Section VI-C CSV and JSON from the archived model outputs, and checks the examples and percentages in Figures 1 and 2. The second also runs the training-curve, endpoint, uncertainty, layout, loss and seed-extension analyses in a temporary working copy. It leaves the distributed files intact.

```text
python -B reproduce.py
python -B reproduce.py --full
```

On Windows, extract near the drive root and choose a short working path such as `D:/nf_tmp` if the system enforces its legacy path-length limit. To choose the disk used for the temporary working copy, add `--work-dir PATH` to the second command. In the table below, paths starting with `data/`, `confirmation/`, `evidence/`, `code/`, `field_analysis/`, `followup/`, `followup_v19/`, `followup_v20/` or `reproduction/` are relative to **experiment_data/**. The two completed evidence ZIPs are read directly by the programs.
